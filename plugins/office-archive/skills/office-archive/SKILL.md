# Office 文件归档

## 核心原则：规划与执行分开

- `plan` 只读，只出方案，不碰任何文件。
- `apply` 必须带 `--confirm`，且方案 6 小时内有效。
- 所以不会出现「模型偷偷移动文件」的情况。**永远先给用户看方案，得到同意再执行。**

## 两条命令

```bash
# 1) 出方案（只读）
python "${CLAUDE_PLUGIN_ROOT}/scripts/office_archive.py" plan \
  --source "D:\下载\待整理" --target "D:\归档"

# 2) 确认后执行
python "${CLAUDE_PLUGIN_ROOT}/scripts/office_archive.py" apply \
  --plan-id <方案 id> --target "D:\归档" --confirm --mode copy
```

`--mode`：`copy` 保留源文件（默认），`move` 校验通过后删除源文件。

## 两种用法

**收件箱 → 归档库**（`--source` 与 `--target` 不同）：按规则把文件搬进分类子目录，文件名前面加 `YYMMDD_`（修改日期）。

**原地整理**（`--source` 和 `--target` 是同一个目录）：只挑还散落在根目录和 `99_未归类/` 里的文件，放进对应子目录。已经归位的不动，所以可以每周重复跑。原地整理强制 `move`。

```bash
python "${CLAUDE_PLUGIN_ROOT}/scripts/office_archive.py" plan --source "D:\归档" --target "D:\归档"
```

## 自定义分类规则

按顺序匹配，第一条命中生效；文件名或相对路径里包含任一关键字就命中。写成一个 JSON 传给 `--rules`：

```json
[
  { "match": ["实验报告", "课程笔记"], "dir": "01_课程作业/程序设计实验", "note": "实验报告" },
  { "match": ["slides", "大纲"], "dir": "04_演示文稿", "note": "PPT 项目" },
  { "match": ["教材", "电子书"], "dir": "05_电子书", "note": "课外阅读" }
]
```

`dir` 支持 `A/B` 表示层级；`note` 写进索引的「说明」列。不传规则就用内置规则（课程作业 / 课程资料 / 项目 / 演示文稿 / 电子书 / 待清理）。没命中任何规则的进 `99_未归类/`，等用户补规则。

## 归档后的 00_索引/

| 文件 | 内容 |
|---|---|
| `文件索引.csv` / `文件索引.md` | 整库快照，每次重写，Excel 双击即开 |
| `迁移清单.csv` | 这一批的「原位置 → 新位置 + SHA256」 |
| `归档日志.jsonl` | 累积日志，还原脚本按它生成 |
| `还原到原位置.ps1` | 把归档里的文件复制回最初位置 |

## 安全边界

- 方案 6 小时后失效，过期重新生成。
- `apply` 缺 `--confirm` 直接拒绝；同一方案不能执行第二次。
- `copy` 保留源文件；`move` 先校验目标 SHA256 一致，再删源文件。
- 校验失败立刻停下并报错，不会留下半套结果。

## 汇报方式

先念方案摘要：多少个文件、哪些分类、有几个重名或重复、几个未命中规则。等用户点头，再执行并把「已归档 N 个、校验 N/N、索引在哪」讲清楚。
